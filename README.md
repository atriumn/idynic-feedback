# Idynic Feedback

Public feedback and bug reports for [Idynic](https://idynic.com) - the AI-powered career companion.

## Reporting Issues

The easiest way to report a bug is using the **Report a Bug** button in the Idynic app. This automatically captures helpful context like your browser and device info.

You can also [create an issue directly](https://github.com/atriumn/idynic-feedback/issues/new/choose).

## Issue Types

- **Bug Report** - Something isn't working as expected
- **Feature Request** - Suggest an idea or improvement
- **Question** - Ask about how something works
